# CRUD 页面

先读根目录 AGENTS.md，核实需求、字段和现有后端接口；缺少关键接口契约时询问，不能猜接口或用本地假成功代替。

## 文件归属

- 页面入口：`src/pages/<module>/index.vue`。
- 页面私有接口与类型：`apis/index.ts`、`apis/type.ts`；通过 `@/http/axios` 的 request 调用。
- 页面复杂时，将表格、表单弹窗放 `components/`，复杂业务状态放 `composables/`；小页面不强制拆分。
- 不把单个业务模块的 API 放进 `common/apis/`，不跨页面导入私有组件。

## 实现

1. 复用现有 Element Plus、`usePagination` 和请求能力；先读实际函数签名。
2. 入口负责请求、搜索和分页装配；拆出的展示组件通过 props/emits 或有明确双向更新需求的 defineModel 交互。
3. 只添加需求及后端支持的操作；没有导出或批量接口就不添加相应按钮。
4. 表单校验遵循后端契约，提交成功后再关闭和刷新；finally 只做加载状态等清理，不能伪装请求成功。
5. 搜索重置与分页监听共用一个请求入口，避免同一操作发出两次请求；接口分页字段按实际协议映射。
6. 单独处理用户取消删除确认；实际删除失败保留原始错误。不要用空 catch 吞掉整个删除链。
7. 路由使用唯一名称、懒加载，并按需求设置角色或权限；参考路由技能，不引入后台布局。

## 验证

检查查询、分页、表单成功与失败、删除取消与失败，以及权限展示；运行 AGENTS.md 指定的相关检查。不要为了示例新增服务端不存在的能力。
